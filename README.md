# abdulalharbi.github.io

Personal website for Abdulrahman Alharbi — computer scientist working in AI and cybersecurity.

**Live:** [abdulalharbi.github.io](https://abdulalharbi.github.io)

## About the site

A single-page portfolio covering research, work, and academic background. Built and maintained as a static site, hosted on GitHub Pages.

## Stack

- Plain HTML, CSS, and a small amount of JavaScript
- No build step, no framework, no dependencies
- Typography: Fraunces, IBM Plex Sans, IBM Plex Mono (via Google Fonts)

## Structure

```
.
├── index.html          # The entire site
├── images/             # Portrait and assets
└── README.md
```

## Local preview

Open `index.html` in a browser. No server required.
